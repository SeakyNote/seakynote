## QDoubleSpinBox允许粘贴更多小数点位数字符串
```cpp
#include <QDoubleSpinBox>
#include <QValidator>
#include <cmath> // 引入 cmath 以使用 std::round 和 std::pow

class MyDoubleSpinBox : public QDoubleSpinBox {
    Q_OBJECT
public:
    explicit MyDoubleSpinBox(QWidget *parent = nullptr) : QDoubleSpinBox(parent) {}

    QValidator::State validate(QString &input, int &pos) const override {
        QValidator::State state = QDoubleSpinBox::validate(input, pos);

        if (state == QValidator::Invalid) {
            bool ok;
            double val = locale().toDouble(input, &ok);
            if (!ok) {
                val = input.toDouble(&ok);
            }

            if (ok) {
                // ================== 核心修改部分 ==================
                // 计算需要放大的倍数 (如保留2位小数，则放大 100 倍)
                double multiplier = std::pow(10.0, decimals());
                
                // 引入极小的补偿值，处理 5.005 -> 5.00499999999 的精度丢失问题
                // 正数加 1e-9，负数减 1e-9
                double epsilon = (val < 0.0) ? -1e-9 : 1e-9;
                
                // 先放大 100倍，加上补偿值，用 std::round 进行严格四舍五入，然后再除以 100
                double roundedVal = std::round(val * multiplier + epsilon) / multiplier;
                
                // 将修正后的完美的双精度浮点数转回字符串
                QString fixedInput = locale().toString(roundedVal, 'f', decimals());
                // ================================================

                state = QDoubleSpinBox::validate(fixedInput, pos);
                
                if (state == QValidator::Acceptable || state == QValidator::Intermediate) {
                    input = fixedInput;
                    pos = input.length();
                    return state;
                }
            }
        }
        return state;
    }
};
```
## word产生"更新域"相关选项
在Word中，右键菜单中出现**“更新域”、“编辑域”、“切换域代码”**这三个选项的根本原因是：**你鼠标右键点击的位置包含了一个“域（Field）”，而不是纯手工输入的普通文字。**

从你提供的图片来看，鼠标停留在“表 1 对象名称”附近。很多人习惯直接手动打字输入“表 1”，普通纯文本是不会有这些选项的。

要让这段文字产生这些选项，你需要将纯文本替换为**Word自动生成的“域”**。以下是三种常见的方法，强烈推荐**方法一**（最符合你图中的场景）：

### 方法一：使用“插入题注”功能（最规范的做法）
如果你图中的“表 1”是表格的标题，应该使用“题注”功能，里面的数字“1”就是一个自动编号的“域”。

1.  把光标放在表格上方想要输入标题的位置。
2.  点击Word顶部菜单栏的**【引用】**选项卡。
3.  点击**【插入题注】**。
4.  在弹出的窗口中，检查“标签”下拉菜单里有没有**“表”**。
    *   *如果没有，点击【新建标签】，输入“表”，点击确定。*
5.  此时“题注”框里会自动显示“表 1”，点击确定。
6.  此时文档中会出现“表 1”，你再在后面手动输入“ 对象名称”。
7.  **测试：** 选中或者把光标放在数字**“1”**上面，点击鼠标右键，你就会看到图中红框标注的“更新域”等选项了。

---

### 方法二：通过菜单手动“插入域”
如果你不想用题注，只是想插入一个能自动更新的元素（比如文档属性、页码、日期时间等）：

1.  将光标放在想要插入域的位置。
2.  点击顶部菜单栏的**【插入】**选项卡。
3.  在偏右侧找到并点击**【文档部件】**（图标通常是几个错落的方块），选择**【域】**。
4.  在弹出的对话框中，左侧选择你想插入的域（例如选择“Date”插入日期，或选择“NumPages”插入总页数），点击确定。
5.  插入完成后，在该内容上右键，就会出现“更新域”的相关选项。

---

### 方法三：使用快捷键手动写“域代码”（进阶）
1.  在需要的位置，按下键盘上的 **`Ctrl + F9`**，这时会出现一对带有灰色底纹的大括号 `{ }`。
2.  在大括号内输入代码，例如输入：`SEQ 表` （注意中间有空格）。
3.  按一下键盘上的 **`F9`** 键（更新域），大括号就会变成数字“1”。
4.  此时右键点击这个数字，就能看到“编辑域”、“切换域代码”等选项。

---

### 💡 辅助小贴士：如何一眼看出哪里是“域”？
为了方便区分普通文字和“域”，建议开启Word的“域底纹”显示：
1. 点击左上角 **【文件】** -> **【选项】**。
2. 选择左侧的 **【高级】**。
3. 向下滚动找到“显示文档内容”模块。
4. 找到 **“域底纹”**，将其设置为 **“始终显示”**，点击确定。
开启后，文档中所有“域”下面都会有一层灰色的背景（打印时不会打出来），你只要在带有灰色背景的文字上右键，就绝对有你要的选项。

## word中如下域代码是什么含义：`SEQ 表 \* ARABIC` 
在 Word 中，域代码 `{ SEQ 表 \* ARABIC }` 的含义是：**为文档中的“表格”生成自动连续排号，并以阿拉伯数字（1, 2, 3...）显示。**

这通常是你使用 Word 的**“插入题注”**（为表格添加名称，如“表1”、“表2”）功能时，Word 在后台自动生成的代码。

以下是该代码的详细拆解：

### 1. 代码拆解说明
*   **`SEQ`** (Sequence)：
    这是 Word 中的“序列”宏命令，告诉 Word 此处需要生成一个递增的序号。
*   **`表`** (Identifier / 标识符)：
    这是该序列的名称。Word 会在整篇文档中寻找带有“表”这个标签的所有 `SEQ` 域，并按它们在文档中出现的先后顺序，依次编号为 1, 2, 3...。
    *（注：如果你给图片编号，这里通常就是 `SEQ 图`；公式就是 `SEQ 公式`）*
*   **`\* ARABIC`** (Format switch / 格式开关)：
    这规定了数字的显示格式。`ARABIC` 代表使用**阿拉伯数字**呈现（即 1, 2, 3, 4）。
    *（注：如果是 `\* ROMAN` 就会显示为罗马数字 I, II, III；如果是 `\* ALPHABETIC` 就会显示为 A, B, C）。*

---

### 2. 这个代码有什么实际好处？
使用这个域代码的最大优势是**动态自动更新**。
如果你在文档中间**插入**了一个新的表格，或者**删除**了某个表格，你不需要自己去手动修改后面的所有表格序号。你只需要：
1. 按 `Ctrl + A` 全选文档。
2. 按 `F9` 键（更新域）。
所有的表格序号就会自动重新按顺序排列正确。

### 3. 如何在 Word 中查看和隐藏这种代码？
*   **显示域代码**：按下键盘上的 **`Alt + F9`**（部分笔记本需按 `Fn + Alt + F9`），原本显示为“表 1”的地方，就会变成 `表 { SEQ 表 \* ARABIC }`。
*   **隐藏域代码（恢复正常显示）**：再次按下 **`Alt + F9`**，它就会重新变成普通的数字。

## MECE
**MECE**（发音类似“米-斯”）是麦肯锡咨询公司前合伙人芭芭拉·明托（Barbara Minto）在《金字塔原理》一书中提出的一个极其重要的逻辑思考原则。它是商业分析、问题解决和结构化表达的基石。

MECE 是英文 **Mutually Exclusive, Collectively Exhaustive** 的首字母缩写。

翻译成中文就是八个字：**相互独立，完全穷尽**。（或者通俗地说：**不重叠，不遗漏**）。

我们可以把它拆开来理解：

### 1. ME = Mutually Exclusive（相互独立 / 不重叠）
意思是：当你把一个大问题或大概念拆解成几个部分时，**这些部分之间不能有交叉，界限必须分明。**

*   **❌ 违反原则的例子：** 把人类分为“男人”、“女人”和“学生”。
    *(错误原因：有重叠。“学生”里既有男人也有女人，分类界限混乱。)*
*   **✅ 符合原则的例子：** 把人类分为“男性”和“女性”。
    *(正确原因：两者没有交叉重叠部分。)*

### 2. CE = Collectively Exhaustive（完全穷尽 / 不遗漏）
意思是：当你把这些拆解出来的部分加在一起时，**必须能拼凑出一个完整的整体，不能有遗漏。**

*   **❌ 违反原则的例子：** 把一年的季节分为“春季”、“夏季”、“秋季”。
    *(错误原因：有遗漏。缺少了“冬季”，加起来拼不成完整的一年。)*
*   **✅ 符合原则的例子：** 淘宝把用户年龄段划分为“18岁以下”、“18-25岁”、“26-35岁”、“35岁以上”。
    *(正确原因：覆盖了所有可能的人群，没有任何一个用户会被漏掉。)*

---

### 为什么在之前那张 PPT 里，我指出它违反了 MECE 原则？

我们在写 PPT 展示产品的“三大核心优势”时，这三个优势（卡片）应该像切比萨饼一样，每一块都代表一个独立卖点，加起来构成了这个产品的“完美全貌”。

回顾那张图片：
*   **左侧卡片（直接本地文件访问）：** 提到了“直接访问**授权文件**夹”。
*   **右侧卡片（安全、透明、可控）：** 提到了“仅访问用户明确**授权的文件**夹”。

**这就违反了 MECE 中的“ME（相互独立 / 不重叠）”原则。**

“授权访问”这个功能点，同时横跨了左侧和右侧的分类。这会导致：
1.  **逻辑混乱：** 观众会困惑，“授权访问”到底算作“本地运行”的特点，还是“安全机制”的特点？
2.  **浪费空间：** 在极其宝贵的 3 张卡片里，你花了两次口舌在讲同一件事，这就意味着你**遗漏（违反了 CE）**了本来可以展示的另一个新卖点。

### 总结
掌握 MECE 原则，最大的好处就是让你说话、写文章、做方案时**逻辑严密，滴水不漏**。能够让听众觉得：“他说得很有条理，而且方方面面都考虑到了。”

## C++原生数组拷贝
在 C++ 中，由于**原生数组不支持直接赋值（拷贝）**，且 `const` 类型的变量**必须在声明时进行初始化**，你不能直接写 `const float rgb[3] = CAMOgl::colorBlack;`。

根据你的具体需求，有以下几种最常用的解决方法：

### 方法一：逐个元素提取初始化（最直接、真正创建了新数组）
如果你确实需要在内存中单独开辟一块名叫 `rgb` 的空间，并将原来的值拷贝过来，你需要逐个元素赋值：
```cpp
const float rgb[3] = {
    CAMOgl::colorBlack[0], 
    CAMOgl::colorBlack[1], 
    CAMOgl::colorBlack[2]
};
```
* **优点**：严格满足了 `const float rgb[3]` 的类型要求，且 `rgb` 是一份独立的数据拷贝，即使 `CAMOgl::colorBlack` 以后被修改了，`rgb` 也不会变。
* **适用场景**：必须创建一份不可变的局部拷贝时。

---

### 方法二：使用数组引用（强烈推荐，避免不必要的拷贝）
如果你仅仅是为了换个简短的名字（比如嫌 `CAMOgl::colorBlack` 太长），而不需要真正拷贝数据，**使用常量引用**是最好的做法：
```cpp
const float (&rgb)[3] = CAMOgl::colorBlack;
```
* **优点**：零开销（没有发生内存拷贝）；保留了数组的长度信息（编译器知道它长度是 3，可以使用 `sizeof(rgb)` 或 `C++11` 的范围 for 循环）。
* **注意**：`rgb` 只是 `colorBlack` 的一个别名（Alias）。如果其他地方修改了 `colorBlack` 的非 const 原值，`rgb` 读出来的值也会跟着变。

---

### 方法三：使用常量指针（常见的 C 风格做法）
在很多图形学（比如 OpenGL）代码中，很多 API 只需要一个指针，数组会自动退化为指针：
```cpp
const float* rgb = CAMOgl::colorBlack;
```
* **优点**：写法简单，同样没有拷贝开销，可以直接传入 `glColor3fv(rgb)` 等 OpenGL 函数。
* **缺点**：丢失了数组维度信息（`sizeof(rgb)` 得到的是指针的大小 4 或 8 字节，而不是 12 字节的数组大小）。

---

### 💡 总结与建议

* 如果你只是想**传参或者简化名字**，请使用 **方法二** `const float (&rgb)[3] = ...` 或 **方法三** `const float* rgb = ...`。
* 如果你**必须拷贝一份独立且不可修改的数据**，请使用 **方法一** `const float rgb[3] = { ... }`。

*(补充：在现代 C++ 中，为了避免这种原生数组无法直接拷贝的尴尬情况，通常建议使用 `std::array<float, 3>`，这样就可以直接 `const auto rgb = CAMOgl::colorBlack;` 一键拷贝了。)*
##  C++11/14/17 的 Erase-Remove 惯用法
```cpp
#include <iostream>
#include <vector>
#include <set>
#include <algorithm> // 包含 std::remove_if

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5, 6};
    std::set<int> to_remove = {2, 4, 6};

    // Erase-Remove 惯用法
    vec.erase(
        std::remove_if(vec.begin(), vec.end(), [&to_remove](int x) {
            return to_remove.count(x) > 0; // count(x) 返回 1 表示存在，0 表示不存在
        }),
        vec.end()
    );

    // 输出结果: 1 3 5
    for (int x : vec) std::cout << x << " ";
    return 0;
}
```
